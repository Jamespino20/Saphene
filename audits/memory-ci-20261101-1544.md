- **Long-term impact if unresolved:** The success logic (exit 0) is triggered when the drift is NOT detected (unfound/mismatch), which contradicts the purpose of a harness. This will lead to false-positive reporting in CI/CD pipelines, causing broken features to pass as 'verified' drift detections.
