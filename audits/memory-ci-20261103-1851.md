- **Location:** `site\vite.config.ts:15`
- **Evidence:**

- **Long-term impact if unresolved:** Grouping all node_modules into a single 'vendor' chunk forces both the main app and docs entry points to load the combined third-party dependencies of the entire project. As dependencies grow, initial page load latency increases significantly and any single package update invalidates the cached vendor bundle for all users.
